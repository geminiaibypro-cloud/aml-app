# AML

This is the first milestone foundation for the AML Android app.

## M1 includes
- Gradle setup with JDK 21 and Android AGP 9.0
- Modules: app, core-model, core-data, core-ui, feature-chat
- Material 3 theme and first empty-state chat UI
- DataStore + SecretStore abstraction
- Room bootstrap layer
- A simple app entrypoint and manifest

## Notes
This is the foundation only. Full provider, local engine, VS mode, agent mode, and media generation are not included in M1.
